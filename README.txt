Запустить Run.

Правила игры.
Два игрока по очереди вводят буквы, пытаясь угадать слово.
Если буква угадана верно, игрок продолжает угадывать.
Если такой буквы в слове нет, ход переходит к другому игроку.
Игрок может открыть случайную букву в слове, но тогда ход перейдет к его сопернику.

Keypad
это клавиатура для ввода букв. Есть кнопка открытия случайной буквы из слова.
Keypad передает действие в WordGuessWindow через интерфейс KeyPadClient.

WordGuessGame
Вызывается WordGuessWindow. Выбирает случайное слово из словаря и следит за состоянием игры.

Prompt
спрашивает имена игроков и передает их в WordGuessWindow, который его и вызвал.

WordGuessWindow
Запускается в Run. Обеспечивает слаженную работу и отображение остальных классов.
